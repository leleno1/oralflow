# Frontend Instructions

- Root `AGENTS.md` remains authoritative.
- M0 frontend work is limited to a buildable status shell.
- Do not implement a workflow canvas, node editor, Agent chat, runtime controls, audio recording, or English-training UI in M0.
- Keep domain and provider logic out of React components.
- Do not call real APIs in M0 tests.
- Use strict TypeScript and test visible behavior.
- Run ESLint, TypeScript checks, Vitest, and the production build for frontend changes.
